# 💧 Reminder Companion

**Your friendly desktop buddy for building better hydration habits.**

Reminder Companion is a desktop application designed to make water reminders more personal and engaging through animated characters, friendly greetings, and simple interactions.

## ✨ Features

- 💧 **Water Reminders** — Get friendly reminders to drink water while working.
- 🧑‍🎤 **Character Selection** — Choose your preferred desktop companion.
- 🎬 **Animated Characters** — Enjoy character arrival animations and interactive reactions.
- 👋 **Personalized Greetings** — Customize your companion's greeting with your name.
- ⏰ **Remind Me Later** — Postpone a reminder when you're busy.
- 🎉 **Interactive Responses** — Respond to reminders with animated reactions.
- 🖥️ **Desktop Experience** — A lightweight desktop companion built with Tauri, Vue 3, TypeScript, and Rust.
